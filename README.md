# Stock Management System

A web-based Stock Management System developed with **Node.js, Express.js, MongoDB, and EJS**. The system allows users to manage products, stock, suppliers, customers, transactions, and financial reports.

### Features

* Product and stock management
* Supplier and customer management
* Sales and restocking transactions
* Financial reports and summaries
* User authentication and access control
* Server-side rendering with EJS
* MongoDB database integration

### Technologies

**Node.js | Express.js | MongoDB | Mongoose | EJS | CSS**
